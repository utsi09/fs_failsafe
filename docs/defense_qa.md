# 본심 방어 Q&A 노트

대화·실험에서 도출된 예상 질문과 데이터 기반 답변. (근거 위치 병기)

## 1. "850ms의 근거는?"
850ms는 FTTI가 아니라 **신선도 채널의 허용시간 상수**다. 시간축 t0~t5를
분리하면(원고 5.1) 카메라 사망의 종단 감지 2.4~2.8초는 850ms 위반이 아니다.
전체 예산은 무개입 실험의 위험 도달 시간(표4: 2~131초)에서 역산하며, 실측
내부 지연(lf P95 0.86s < 3s, cf P95 3.21s < 8s)이 고장별 예산을 충족한다.
민감도 500/850/1000ms 결과 불변, 최종 권고 500ms(mrm_handler 0.5s 정합).

## 2. "baseline이 불공정하지 않나?"
감지·판단은 동일하게 통제하고 대응만 순정 MRM — 순정 진단은 노이즈를 아예
못 보므로(감지 능력 비교가 되어버림) 대응 전략을 분리하려면 이 통제가 필수.
"감지 부재" 시나리오는 MRM-off 조건이 별도 제공(표4).

## 3. "Autoware에도 pull_over 있는데?"
인정하고 서론에서 명시(버전·구성 한정). 기여는 갓길 기동이 아니라 "고장
종류·정도·잔여능력 기반 구분 선택의 감독 계층". [잔여 조사: 본 빌드에서
pull_over MRM 활성화 가능성 — 가능 시 직접 비교 20케이스 추가 여지]

## 4. "왜 다 10Hz로 검사?"
수신은 센서 전속(콜백 적산), 평가만 10Hz. 틱 기여 지연 ≤0.1s는 실측 종단
치에 포함된 채 예산 충족. AUTOSAR WdgM 100ms 관행·스택 판단 주기와 정합.
FTTI<0.3s급 ODD에선 이벤트 구동 평가 필요(한계 명시).

## 5. "파라미터가 너무 많다"
부록 일람 + 4유형 분류: 도출형(갓길 7m=실측 경계 6.3/7.8m, τ_fresh=정합),
민감도 검증형(밴드: 무감 계곡 [0.65,0.9] 등가·낮추면 계단식 상실; CUSUM
3x3 전 격자 유지), 섭동 강건형(비용 가중치 ±50% 800회 최상위 불변 —
변별은 게이트·거리가 지배), 한계 인정형(섹터 가중 등).

## 6. "동적 감지예산이 실제로 뭘 했나?"
발동 실증: 근접 상황에서 마감<850ms 틱 동적 15~3,373 vs 고정 0. 종단
이득은 폐루프에서 구조적 측정 불가 — 건강한 스택이 TTC<1s 창을 선제
감속으로 자기 소멸시킴(계측: 20m 급제동 후에도 TTC 6.4~11.3s). 따라서
심층 방어 장치로 규정, 이득 정량화는 개루프 자극 시험(향후).

## 7. "IMU 백색노이즈 못 잡던데?"
잔차 채널의 구조적 사각(양쪽 신호가 GNSS 앵커, 임계 r>base+0.86m 미달).
단 실측 무해(243~300m 정상 주행) — 심각도 곡선 요구 비위반. 유해 모드
(바이어스)는 전용 채널이 1.8s에 감지(주행 중 주입 14/14).

## 8. "부팅 기준선이 정상이란 보장은?"
실험은 프로토콜(주입 10~45s)이 보장. 실차 배치는 한계 — 공장 기준값 교차
검증을 완화책으로 제시. 부팅-고장 센서도 '추가 악화'는 감지되며 침묵
채널은 기준선 무관.

## 9. "도심→수풀 가면 오탐 아닌가?"
기준선이 적응형(1%/frame, 1.5배 게이트: 서행 변화 추종·급등 불추종).
수풀 많은 Town07 경로에서 무고장 146케이스 오경보 0으로 장면 강건성 실증.
급격한 장면 경계는 한계·장면 조건부 기준선은 향후 과제. (명칭도 그래서
'상대 거리불연속 점수'.)

## 10. "일반화 되나? (단일 맵·경로)"
수치는 ODD 한정 사례연구로 명시, 주장은 메커니즘(비단조·채널별 감지·
유예x능력 선택)에 한정. 제2 경로에서 감지 대역 재현(ln 1.0~1.1s, gn 1.4s,
cf 2.9s) 확인 — 대피 성공률 저하는 후보 지도 커버리지 종속(수동 주석 한계
로 정직 보고).

## 11. "비단조 현상이 스택 아티팩트 아닌가?"
기제를 인식 객체 로그로 직접 확인(전방 12m 내 유령: mid 11~70% vs high
3~10%, 객체 중앙값 3 vs 0~1). 이상점 기각은 실용 스택 일반의 구조이므로
"전이의 존재"는 일반적, 전이점 σ_crit은 스택별 상이로 한정. [보강 여지:
필터 임계 스윕으로 전이점 이동·현상 유지 확인]

## 12. "행동트리가 왜 필요한가?"
알고리즘 기여가 아니라 구현 구조(병렬 감시·모듈 교체·실행 추적)로 한정
서술(원고 3.1). 성능 우위 주장 없음.

## 13. "오경보 0을 믿을 수 있나?"
버전 분리 보고: v1 0/77(상한 3.9%), v2 게이트 0/19, v2.1 최종 0/50(상한
6.0%), 폭우 0/10 — 통산 0/146. 개발 중 벽시계 기준 침묵 판정 오탐 4건은
시뮬 시계 기준으로 수정 후 0/50 재검증(교훈으로 6장 수록).

## 14. "복합 고장은?"
라이다+카메라 동시 주입 9유효: 감지 0.6~0.8s(단독보다 가속 — min() 합성),
전원 즉시 위임(자동 보수화).
