[1] 밴드 상단 임계 (기본 0.7) — 재판정, armed 게이트 적용
--------------------------------------------------------------------------------
고장 시 지각점수 정착 구간(실측): 0.42~0.65 / 정상 주행: >=0.9
-> [0.65, 0.9]가 "무감 계곡": 이 구간 내 어떤 임계든 판정 동일
임계를 내리면 놓침 발생(재판정):
  0.6 -> cn 3/6만 도달(+27.7s 지연)
  0.5 -> cf 12/40만 도달(+48s)
  0.4 -> lf 7/43만 도달
  0.3 -> lf/cf 계열 지각 경로 감지 소멸
심사 답변: "0.7은 무감 계곡 [0.65,0.9] 내 선택이며 구간 내 등가.
경계를 낮추면 감지 상실이 계단식으로 발생함을 전수 재판정으로 확인."

[2] 밴드 하단 임계 (기본 0.3)
--------------------------------------------------------------------------------
지각 경로는 0.3에 거의 도달하지 않음(ln 2/7, cf 5/40, lf 0/43)
-> floor DEFER는 사실상 위치 채널(min 결합) 전담: 실측에서 DEFER 발동은
   gn high(잔차), imb(바이어스), gb(침묵), 즉 위치 붕괴 시나리오에서만.
심사 답변: "0.3은 '지각 저하는 이동(MOVE), 위치 붕괴는 정지(DEFER)'라는
역할 분리를 구현하는 값이며, 위치 채널 점수는 고장 시 0.05~0.23으로
급락(수식 exp(-excess/0.55))해 0.2~0.4 어디에 둬도 분류 동일."

[3] CUSUM (k, h) — σ 시계열 재적산 (ln 7케이스)
--------------------------------------------------------------------------------
k ∈ {0.25, 0.5, 1.0}x기준선, h ∈ {0.25, 0.5, 1.0}m 3x3 전 격자:
감지 7/7 유지, 지연 0.1~0.4s (σ 도약이 기준선의 ~4배라 여유 큼)
심사 답변: "채택값(k=0.5xbase, h=0.5m)은 3x3 격자 전 영역에서 동작이
동일한 평탄 영역 내부에 있음."

[4] k-미스 (기본 3주기) — 해석표 (수신주기 실측 50ms 기준)
--------------------------------------------------------------------------------
k=2 -> 의심 발동 100ms: 정상 지터(단발 결손, DDS 재전송)와 충돌 위험
k=3 -> 150ms: 업계 라이다 감시 디바운스(3회 연속) 관행과 일치 [채택]
k=4 -> 200ms: 오탐 여유 증가, 감지 +50ms
효과 경로: 침묵 감지의 '의심' 단계 시점만 ±50ms 이동 — 종단 감지(0.75s)
대비 7% 이내. 어느 값이든 예산 충족.

[5] 바이어스 임계 (기본 0.2 rad/s, 3s 지속) — 해석표 + 실측
--------------------------------------------------------------------------------
주입 0.3/1.0 rad/s vs 임계:
  0.1 -> 두 강도 모두 감지(여유 3x/10x), 단 EKF-IMU 정상 불일치(~0.05)
         대비 여유 2x로 감소 — 오탐 여유 축소
  0.2 -> 두 강도 감지(실측 14/14 주행 중), 정상 불일치 대비 4x [채택]
  0.3 -> mid(0.3)가 경계선상 — 지속 조건과 결합 시 감지 불안정 예상
심사 답변: "임계는 주입 최소 강도의 2/3, 정상 불일치의 4배 지점."

[6] 비용함수 가중치 (w_time 7 / w_tl 200 / w_sec 500 / w_loc 14)
--------------------------------------------------------------------------------
±50% 무작위 섭동 800회(8 경로지점 x 2 고장 프로파일 x 50): 최상위 후보
불변 800/800 (100%).
구조적 이유: 후보 간 순위의 변별력은 (a) INF 게이트(신호등 관측성,
최소 접근거리)와 (b) 접근거리 항이 지배하고, 섹터·loc 항은 후보 간
공통이라 가중치 스케일이 순위에 사실상 중립.
심사 답변: "가중치는 항 간 우선순위(게이트 > 안전 > 시간)의 서수적
인코딩이며, 절대값 ±50%에 선택이 불변임을 스윕으로 확인 — 정밀 튜닝을
주장하지 않고 순위 강건성을 주장한다."

[7] τ_fresh (500/850/1000ms) — 실주행 (기존 완료)
--------------------------------------------------------------------------------
성공률·오경보 불변, 관측 감지 변화 <0.3s. 500ms 권고(하위 스택 정합).

--------------------------------------------------------------------------------
한계 명시 (논문에 그대로)
--------------------------------------------------------------------------------
재판정 민감도는 "판정 계층"(감지 시점·분류)까지 검증하며, 판정 변경 후의
폐루프 결과(성공률)는 재현하지 않는다. 폐루프 민감도는 τ_fresh 실주행이
대표한다. 밴드/σ 시계열 해상도는 1s(로그 출력 주기).
